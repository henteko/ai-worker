# OMOCHA WORKS — Autonomous Ops Console

AIエージェントが勝手に働いてくれている（**ように見えるだけで実際は何もしていない**）フェイク業務ツール。

5体のAIエージェントが画面上をカーソルで飛び回り、カンバンのタスクカードを掴んで運び、
レビューし、承認し、KPIを伸ばし、インシデントに緊急対応します。すべて演出です。
あなたは眺めているだけでOKです。

## 起動方法

`index.html` をブラウザで開くだけ。サーバー不要・外部通信ゼロ・完全オフライン動作。

```
open index.html
```

## 見どころ

- **AIカーソル** — Figma のマルチプレイヤーカーソル風に5体のエージェントが動き回り、カードをドラッグ&ドロップ
- **カンバンボード** — バックログ → 進行中 → レビュー → 完了 をタスクが自動で流れる（たまに差し戻しも発生）
- **KPI連動** — タスク完了のたびにトースト通知が飛び、完了数・自動化時間・売上インパクトがカウントアップ、スパークラインが伸びる
- **インシデント** — 時々アラートが発生し、手すきのエージェントが緊急対応。SLAが下がり、CPUが赤くなり、復旧すると回復
- **ライブチャート** — 処理スループットがリアルタイム風に描画（ホバーでツールチップ）
- **アクティビティフィード** — 全エージェントの働きぶりがひたすら流れてくる

右上の「一時停止」で全エージェントの動きを止められます（サボり検出機能はありません）。

| ファイル | 内容 |
